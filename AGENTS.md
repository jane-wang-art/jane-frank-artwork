# Repository working rules

Work only in `jane-wang-art/jane-frank-artwork` for this project unless the owner explicitly changes the scope. Keep it public. Do not modify `MediciHouse07/art_work` or other repositories as a side effect.

Preserve the author credit Jane Wang, copyright/publishing identity jane-wang-art, canonical source URL, and paid written-permission plus audience-visible-attribution policy. Do not replace the policy with an open-source or Creative Commons grant without explicit approval.

Publish only owner-selected artwork. The nine existing terrace PNGs are the selected public set. Preserve their original bytes, individual files, reading order and recorded hashes. Do not silently redesign, resize, regenerate or overwrite artwork; use a new version for later approved revisions.

Keep rejected drafts, other artists' reference images, raw conversations, credentials and private legal/customer/payment records out of public commits. Do not treat file possession or generation as approval for publication.

Record provenance accurately, including AI assistance, source filenames and genuine timestamps when known. Do not invent creation dates, ownership assignments, registrations or signatures. A hash and Git history are not a copyright registration.

Read existing files and branch state before editing. Preserve unrelated changes, use non-force updates, check image links and compare imported file hashes. Report actual completed work, not just plans. Temporary transfer workflows must be removed after the authorized one-time operation; do not configure ongoing publication without approval.
